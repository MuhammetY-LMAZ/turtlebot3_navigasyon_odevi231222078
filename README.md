# turtlebot3_navigasyon_odevi231222078

Bu proje, ROS Noetic ve TurtleBot3 kullanılarak hazırlanmıştır. 
Belirlenen harita üzerinde robotun otonom olarak 5 farklı noktaya sırayla gitmesini sağlar.

## Kullanım
1. Simülasyonu başlatın.
2. Navigasyon paketini `odev_haritam.yaml` ile çalıştırın.
3. `python3 odev_gorev.py` komutuyla görevi başlatın.
